# QvarcY · .github

Shared GitHub configuration and community defaults for repositories maintained under the **QvarcY** account.

## Default files

GitHub uses these files automatically for repositories that do not provide their own version:

- `.github/FUNDING.yml` — GitHub Sponsors and Buy Me a Coffee links
- `CONTRIBUTING.md` — contribution guidelines
- `SECURITY.md` — private vulnerability reporting guidance
- `SUPPORT.md` — where to ask for help or report problems
- `CODE_OF_CONDUCT.md` — basic collaboration and moderation expectations
- `.github/ISSUE_TEMPLATE/bug_report.yml` — structured bug reports
- `.github/ISSUE_TEMPLATE/feature_request.yml` — structured feature requests
- `.github/PULL_REQUEST_TEMPLATE.md` — concise pull request checklist

Repository-specific files always take precedence over these defaults.

## Funding

Open-source work can be supported through:

- [GitHub Sponsors](https://github.com/sponsors/QvarcY)
- [Buy Me a Coffee](https://buymeacoffee.com/craftin)

Support is optional and helps cover the time, infrastructure, testing, domains, and development tools used to build and maintain practical open-source projects.

Sponsorship does not buy priority support, guaranteed fixes, consulting, or response-time commitments unless a specific project explicitly says otherwise.

## Scope

This repository contains shared account-level defaults only. Project-specific documentation, licenses, release notes, and technical policies belong in the individual repositories.
