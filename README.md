# QvarcY · .github

Shared GitHub configuration for repositories maintained under the **QvarcY** account.

## What lives here

- Default funding configuration for repositories that do not define their own `.github/FUNDING.yml`
- Shared community-health files that may be added later
- Account-wide repository defaults where GitHub supports them

## Funding

Open-source work can be supported through:

- [GitHub Sponsors](https://github.com/sponsors/QvarcY)
- [Buy Me a Coffee](https://buymeacoffee.com/craftin)

Support is optional and helps cover the time, infrastructure, testing, domains, and development tools used to build and maintain practical open-source projects.

Individual repositories can override these defaults by providing their own configuration.
