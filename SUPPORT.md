# Support

Thanks for using projects maintained under the **QvarcY** account.

## Bugs and feature requests

For repository-specific bugs, regressions, or feature ideas, use that repository's **Issues** section and provide enough context to reproduce or understand the request.

Before opening a new issue:

- check the README and project documentation
- search existing issues
- include relevant version and environment details
- add logs, screenshots, or a minimal reproduction when useful

## Questions

If the repository has GitHub Discussions enabled, use Discussions for general questions that are not bugs.

If Discussions are not available, a concise issue is fine when the question is directly related to using or developing the project.

## Security

Do not post vulnerability details publicly. See the default [Security Policy](SECURITY.md).

## Sponsorship

Sponsorship is optional and helps support ongoing open-source work. It does **not** purchase priority support, guaranteed fixes, consulting, or response-time commitments unless a repository explicitly says otherwise.

Repository-specific support instructions override this file.
